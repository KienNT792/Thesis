# Thesis

Data pipeline and experiments for the FSB AiMSE graduation project on an LLM-derived news fear index
for short-term VN30 direction forecasting.

- Data collection (GitHub Actions): see [docs/DATA.md](docs/DATA.md)
- Config: `config/` (RSS feeds, tickers, price provider)
- Collectors: `scripts/`, tests: `tests/`
- Collected data: `data/` (committed by the workflows)
